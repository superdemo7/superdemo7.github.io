# Portafolio de Arturo Mandujano

Página de contratación en HTML estático. Se publica en [superdemo7.github.io](https://superdemo7.github.io/).

El idioma queda en la URL: `?lang=es` o `?lang=en`.

Para verla en local, desde esta carpeta:

```
python -m http.server 8765
```

Luego abre `http://127.0.0.1:8765`.
