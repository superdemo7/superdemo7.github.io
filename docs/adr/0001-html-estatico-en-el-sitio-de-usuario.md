# HTML estático en el sitio de usuario de GitHub

El portafolio se publica en `superdemo7.github.io`, el único sitio de usuario de esa cuenta, y sustituye el concurso que estaba ahí. Se escribe en HTML, CSS y un script corto de idioma, sin generador, porque el contenido son dos casos y GitHub Pages sirve `index.html` desde la rama. Se descartaron Astro y Next.js: habrían añadido un build para una página que no es una aplicación.
